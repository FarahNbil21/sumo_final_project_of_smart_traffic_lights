In this simulation, we demonstrate the traffic congestion scenario using SUMO.
The intersection currently operates under a fixed-time traffic light system.

As shown in the video, vehicles accumulate unevenly across different lanes.
Despite the variation in traffic density, the signal timing remains constant.
This leads to unnecessary waiting time and increased congestion in high-density lanes.

This simulation represents the baseline model.
Our goal is to enhance this system by integrating an AI-based traffic control model.
The model will dynamically adjust green light duration based on real-time traffic density.
By applying intelligent signal control, we aim to reduce average waiting time, minimize congestion, and improve overall traffic flow efficiency.

This simulation serves as the foundation for implementing a smart, scalable traffic management system.
